# whyyoufeelsobad.com

The personal way in to Demismatch. Plain static files: `index.html`, `look.css`, `style.css`, `fonts/`.
Serve the repo root as it is (GitHub Pages, branch main). The domain is set in `CNAME`.

`look.css` is the one look for every Demismatch site (colours, typefaces, text sizes, the top bar, the Cor banner, the foot). It is a copy. Change the master, never this copy. The home page uses it; the pages under `mock/` do not yet.
